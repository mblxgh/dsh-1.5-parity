# dsh-1.5-parity

DeepSeek Harness 0.2.x 的补丁集：把对话流显示与工作区标签恢复至 0.1.5 的行为。

适用于官方桌面端，也适用于自行解包的目录树。已在 0.2.0-rc.2 与 0.2.2-rc.5 上验证。

---

## 修正内容

0.2.x 存在两处影响正常使用的问题。

**工作区完整性标签。** 沙箱向工作区写入 Low 完整性标签，且该标签可被继承。被标记目录下的程序随之降权，无法读取其他位置，无法运行需要常规权限的程序。工作区与程序目录处于同一路径下时，程序目录一并受影响。

**插件注入拦截。** 插件发送的消息来源不被识别，按非预期来源丢弃。记忆、预设、技能目录等注入内容无法进入对话，模型不可见。所有依赖注入的插件因此失效。

---

## 相较于 0.2.0 的改动

### 运行行为

| 0.2.x 原版 | 本补丁 |
|---|---|
| 向工作区写入 Low 完整性标签，标签可继承 | 保留现有标签，不写入 |
| 沙箱令牌的完整性级别降至 Low | 仅剥离特权，完整性级别不变 |
| 仅识别 `runtime-context` 一种消息来源，其余来源丢弃 | 增加 `plugin` 来源，两处校验均放行 |

### 对话流界面

| 0.2.x 原版 | 本补丁 |
|---|---|
| 上下文注入内容归入「已完成」折叠区，展开后显示原始消息标识 | 独立成行，显示中文名，可展开查看快照 |
| 默认视图为「详情」档：已完成轮次折叠，历史轮次按步骤分组 | 全部展开，不折叠、不分组 |
| 行间距取值 0 / 4 / 12 / 16px 混用 | 统一为 16px |
| 思考正文按 markdown 渲染，字色继承正文，字号继承容器，段落含外边距 | 按纯文本渲染，13px / 20px，灰色，保留原始换行 |
| 思考摘要行取最后一个已完成段落的首行 | 取全文最后一个非空行 |
| 标签与内容使用同一色阶 | 标签使用高一级色阶 |
| 轨迹行仅显示类型标签，来源需展开详情查看 | 行尾附带来源信息 |

## 使用方法

### 环境要求

- Node.js 18 或以上
- PowerShell 7（`pwsh`）
- 首次运行需联网获取解包工具

### 桌面端

双击 `patchkit/装补丁.cmd`。脚本自动查找安装目录。首次运行将官方归档解包为目录（数百 MB，约一分钟），此后仅修改文件。

安装前需关闭客户端。

脚本仅识别若干默认路径。若安装目录带版本号后缀，或同一磁盘存在多份安装，需以 `-Root` 指定目标。

### 指定目录

```powershell
pwsh -File patchkit/install.ps1 -Root "D:\DeepSeek Harness"
```

### 检查状态

不修改任何文件，仅报告每条补丁的状态。

```powershell
pwsh -File patchkit/install.ps1 -Check
```

### 恢复原版

```powershell
pwsh -File patchkit/install.ps1 -Rollback
```

归档文件未被删除或修改，可随时恢复。

### 部分应用

```powershell
pwsh -File patchkit/install.ps1 -Only ui-label             # 按组
pwsh -File patchkit/install.ps1 -Only chat-context-labels  # 按单条
pwsh -File patchkit/install.ps1 -Skip server               # 跳过某组
```

查看全部补丁清单：

```powershell
node patchkit/patch.mjs --list
```

## 注意事项

**安装前关闭客户端。** 文件被占用时无法修改。

**首次运行耗时较长。** 解包归档需写入数百 MB，约一分钟。后续运行仅修改文件，数秒完成。

**客户端自动更新后补丁失效。** 更新会替换应用文件，属预期行为。更新完成后重新执行安装即可，无需先恢复原版。

**出现未匹配的补丁条目。** 该处原文与目标版本不一致。以 `-Check` 查看具体条目及其标识。

**客户端无法启动。** 执行 `-Rollback` 恢复原版。

**需撤销单条补丁。** 从 `node_modules\_patchkit-backup\` 取回对应原件覆盖，再以 `-Skip <标识>` 重新应用。

**更换版本。** 先执行 `-Rollback` 恢复原版，再重新安装补丁。
