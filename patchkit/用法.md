# 命令速查

```powershell
# 双击入口（自动查找安装目录）
装补丁.cmd

# 指定安装目录
pwsh -File install.ps1 -Root "D:\DeepSeek Harness"

# 查看状态，不修改文件
pwsh -File install.ps1 -Check

# 恢复官方原版
pwsh -File install.ps1 -Rollback

# 仅应用指定分组 / 指定条目
pwsh -File install.ps1 -Only ui-label
pwsh -File install.ps1 -Only chat-context-labels

# 跳过指定分组
pwsh -File install.ps1 -Skip server

# 查看全部补丁清单
node patch.mjs --list
```

安装前需关闭客户端。归档文件未删除，可恢复原版。
